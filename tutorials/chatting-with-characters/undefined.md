# 새로운 채팅하기

\+ Make New Storychat

한 캐릭터와 여러가지 페르소나를 기반으로 대화하고 싶으신가요? 채팅방의 사이드메뉴에서 +Make New Storychat 버튼을 눌러 이 캐릭터와 다른 대화를 생성할 수 있습니다.



View All Storychats 버튼을 누르면 해당 캐릭터에 생성된 모든 스토리챗들의 목록을 확인할 수 있습니다.



Reset을 눌러 현재 접속해있는 스토리챗의 채팅을 초기화할 수 있습니다. 이 경우, 기존의 채팅 내용이 모두 삭제됩니다.&#x20;



Delete버튼을 눌러 현재 접속해있는 스토리챗을 삭제할 수 있습니다. 삭제된 스토리챗은 복구할 수 없습니다.
