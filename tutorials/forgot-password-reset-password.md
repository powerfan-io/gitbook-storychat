# Forgot Password? Reset password

Steps:\
1\. Click the "forgot password" button in the sign in page : [https://web.storychat.app/forgot-password](https://web.storychat.app/forgot-password)\
2\. Type your email and check your email or spam folder for the One Time Pass (otp) code \
3\. Coppy the otp code to email otp and reset with new password at [https://web.storychat.app/reset\_password](https://web.storychat.app/reset_password)
