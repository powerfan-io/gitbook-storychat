# Image Generation

### 🎨 Image Generation – Create with Storychat AI

Bring your imagination to life with Storychat’s AI image generation.

Characters with rich, expressive images attract more attention and engagement from other users.

***

#### 🛠 How to Generate Images

1. Go to the Create page.
2. Tap Create Image to open the image generation tool.
3. Enter your prompt to instantly create an image.
4. Each generated image costs 100 SP.

#### 🖌 Two Ways to Create

* Text to Image → Enter a prompt and generate an image from scratch.
* Image to Image → Upload a base image and modify it.
  * Example: Upload your Character’s image and say, _“Change the outfit color to red.”_
